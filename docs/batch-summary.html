Batch Compilation Summary

Overview

Batch compilation is built into jackc (since version 1.1.0). It replaces the earlier standalone compile_all.sh script, which is not part of this repository.

At a Glance

Task Command
Compile one directory jackc src/
Compile a directory tree jackc -r src/
Mirror output into another directory jackc -r src/ -o build/
Preview what would happen jackc -r -n src/
Clean rebuild jackc -r --clean src/
Preview a clean rebuild jackc -r --clean -n src/
Show help jackc --help

Behaviour

  • Files are compiled in sorted path order; each .jack file produces one .vm file.
  • With -r, hidden directories (.git, .venv, ...) are skipped and symlinked directories are not followed.
  • Compilation continues after a failure; the summary lists every failed file.
  • --clean removes .vm files only from directories that receive output (for a single file: only its target).
  • --dry-run never creates, overwrites or deletes anything.
  • Colour is used only when writing to a terminal and NO_COLOR is unset.

Exit Status

Code Meaning
0 Every file compiled (dry run: at least one .jack file found)
1 At least one file failed, the input path does not exist, or no .jack files were found
2 Invalid command line (for example -r with a single file)

Migrating From compile_all.sh

Old New
./compile_all.sh . jackc -r .
./compile_all.sh src/ --dry-run jackc -r src/ --dry-run
./compile_all.sh src/ --clean jackc -r src/ --clean
./compile_all.sh src/ --verbose jackc -r src/ (every file is always listed)
./compile_all.sh --help jackc --help

Differences:

  • --clean is narrower: directories without .jack files are never cleaned.
  • -v/--verbose now means "show Python tracebacks for internal compiler errors".
  • Syntax errors are printed as file:line:col: message beneath the failing file.
  • Elapsed time is not reported.
  • No Bash is needed, so it also works natively on Windows.

Testing

The batch options are covered by the automated test suite (pytest), which checks recursion, hidden-directory skipping, mirrored output, --clean scoping, dry runs, failure reporting and exit codes. GitHub Actions runs the suite on Python 3.8, 3.10 and 3.12 for every push and pull request.
