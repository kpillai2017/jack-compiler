Batch Compilation Script - Complete Summary

Overview

A professional-grade shell script (compile_all.sh) that recursively compiles all Jack files in a directory tree, including files in subdirectories. It's production-ready, well-tested, and thoroughly documented.

What You Get

Core Script

    • Quick Usage

    
# Make executable (first time only)
chmod +x compile_all.sh

# Compile current directory
./compile_all.sh .

# Compile specific directory
./compile_all.sh src/

# Preview without compiling
./compile_all.sh . --dry-run

# Clean and rebuild
./compile_all.sh . --clean

# Verbose output
./compile_all.sh . --verbose

# Help
./compile_all.sh --help

    Example Scenarios

    Scenario 1: Simple Project

    
project/
├── Main.jack
├── Game.jack
└── Player.jack

    Scenario 2: Nested Structure

    
project/
├── Main.jack

$ ./compile_all.sh . --dry-run
(See what will be compiled)

$ ./compile_all.sh .
(Actually compile)

    Scenario 4: Rebuild From Scratch

    
$ ./compile_all.sh . --clean
(Removes old .vm files, then recompiles)

    Features Explained

    Recursive Discovery

The script uses find to automatically locate all .jack files:

  • No file path hardcoding
  • Supports unlimited directory depth
  • Finds files in any order
  • Processes them systematically

    • Directory Preservation

.vm files are generated in the same directory as .jack files:

  • Maintains project structure
  • No need to manually organize output
  • Easy to integrate with version control

    • Progress Tracking

Real-time feedback during compilation:

  • Progress dots for each file
  • Summary statistics at end
  • Compilation times reported
  • Success/failure counts

    • Error Recovery

Handles failures gracefully:

  • Continues compilation on errors
  • Reports all failed files at end
  • Exits with proper status code
  • Clear error messages

    With Make

Troubleshooting

"Script not found"


chmod +x compile_all.sh

"Python not found"


# Install Python 3
brew install python3  # macOS
sudo apt-get install python3  # Linux

"Compiler not found"


# Run from jack-compiler directory
cd jack-compiler
./compile_all.sh .

"Files failed to compile"


# Use verbose mode to see errors
./compile_all.sh . --verbose

Advanced Usage

Compile Only Subdirectories


./compile_all.sh src/system/
./compile_all.sh src/ui/

Save to Log File


./compile_all.sh . --verbose > build.log 2>&1
