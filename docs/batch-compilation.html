Batch Compilation Guide

Overview

jackc compiles a single .jack file, every .jack file in a directory, or a whole directory tree. Batch compilation is built into the compiler — there is no separate script to install — and works the same on macOS, Linux and Windows.

jackc src/                  # every .jack file in src/
jackc -r src/               # src/ and all its sub-directories
jackc -r src/ -o build/     # ... with output mirrored under build/

Features

  • Directory mode — pass a directory to compile every .jack file in it
  • Recursive mode (-r) — walk sub-directories; hidden directories such as .git and .venv are skipped
  • Mirrored output (-o) — with -r, the source tree is recreated under the output directory
  • Clean builds (--clean) — delete stale .vm files before compiling
  • Dry run (-n) — preview exactly what would be cleaned and compiled
  • Keeps going on errors — every file is attempted; failures are listed at the end
  • Script-friendly — exit status 0 only if every file compiled; colour is disabled automatically when output is redirected

Installation

git clone https://github.com/kpillai2017/jack-compiler.git
cd jack-compiler
pip install -e .
jackc --version

If you prefer not to install, run python -m jack_compiler from the repository root (after pip install -r requirements.txt) anywhere jackc is shown below.

Usage

jackc [-h] [-o OUTPUT] [-r] [--clean] [-n] [-v] [--version] input

Compile one directory

jackc src/

Compiles src/*.jack to src/*.vm. Sub-directories are ignored.

Compile a directory tree

jackc -r src/

Each .vm file is written next to its .jack file.

Write output somewhere else

jackc src/ -o build/        # flat: build/Main.vm, build/Game.vm, ...
jackc -r src/ -o build/     # mirrored: build/game/objects/Point.vm, ...

Preview, then clean-build

jackc -r --clean --dry-run src/
jackc -r --clean src/

Options Reference

Option Description
input A .jack file or a directory
-o, --output OUTPUT Output .vm file (single file) or directory (default: next to the source)
-r, --recursive Also compile sub-directories, mirroring the tree under OUTPUT
--clean Delete existing .vm files in each output directory before compiling
-n, --dry-run Show what would be cleaned and compiled; change nothing
-v, --verbose Print a Python traceback for internal compiler errors
--version Print the compiler version
-h, --help Show help

Where Output Goes

Command Source Output
jackc src/ src/Main.jack src/Main.vm
jackc src/ -o build/ src/Main.jack build/Main.vm
jackc -r src/ src/game/Math.jack src/game/Math.vm
jackc -r src/ -o build/ src/game/Math.jack build/game/Math.vm
jackc src/Main.jack src/Main.jack src/Main.vm
jackc src/Main.jack -o out/X.vm src/Main.jack out/X.vm

Output directories are created as needed. Existing .vm files with the same name are overwritten.

What --clean Removes

--clean exists so that a build never leaves out-of-date .vm files behind — for example from a class you deleted or renamed, or from a file that now fails to compile.

  • Directory input: every *.vm file in each output directory that this run writes to. With -r, that is each directory (or mirrored output directory) that contains .jack files.
  • Single-file input: only that file's own target .vm.
  • Directories that contain no .jack files are never touched, and cleaning inside each directory is not recursive.

Caution: if an output directory also holds hand-written .vm files (for example, copied OS classes), --clean will remove them. Run with --dry-run first to see the exact list.

Common Workflows

nand2tetris project (one directory per program)

jackc projects/11/Pong/            # then load projects/11/Pong/ in the VM Emulator

All programs in a course folder

jackc -r --clean projects/11/

Keep sources and build output separate

jackc -r --clean src/ -o build/

Integration Examples

Make

.PHONY: build
build:
    jackc -r --clean src/ -o build/

make stops automatically because jackc exits non-zero when any file fails.

GitHub Actions

- name: Compile Jack sources
  run: |
    pip install git+https://github.com/kpillai2017/jack-compiler.git
    jackc -r --clean src/ -o build/

Shell scripts and log files

set -e
jackc -r src/ > build.log 2>&1     # all output goes to stdout; colour is off when redirected

Troubleshooting

jackc: command not found — activate the virtual environment you installed into, or use python -m jack_compiler.

No .jack files found in src/ — without -r only the top level is searched. Add -r to include sub-directories.

jackc: error: --recursive requires a directory as input — -r cannot be used with a single .jack file.

Files under .something/ are not compiled — hidden directories are skipped in recursive mode. Pass the directory explicitly, e.g. jackc .hidden/.

Old .vm files still present — a file that fails to compile keeps its previous .vm unless you use --clean.

FAQ

Does it stop at the first error? No. Every file is attempted, and all failures are listed in the summary.

In what order are files compiled? Sorted by path, so output is deterministic.

Are symbolic links followed? Symlinked files are compiled; symlinked directories are not descended into during -r.

Does it run on Windows? Yes — jackc is a regular Python command and needs no shell, WSL or Git Bash.
