Batch Compilation Guide

Overview

The compile_all.sh script provides a convenient way to recursively compile all Jack files in a directory tree, including files in subdirectories. It automates batch compilation while preserving the directory structure.

Features

✅ Recursive Compilation

  • Automatically finds all `.jack` files in the directory and all subdirectories
  • No manual file listing needed

✅ Directory Preservation

  • Generates `.vm` files in the same location as corresponding `.jack` files
  • Maintains original directory structure

✅ Progress Tracking

  • Shows real-time progress during compilation
  • Displays compilation statistics at the end
  • Reports errors with file locations

✅ Flexible Options

  • Dry-run mode to preview without compiling
  • Verbose mode for detailed output
  • Clean mode to remove old `.vm` files first

✅ Error Handling

  • Graceful error reporting
  • Continues compilation even if one file fails
  • Summary of failed files at the end

    • Installation

The script is included in the jack-compiler directory. Make sure it's executable:


chmod +x jack-compiler/compile_all.sh

Usage

Basic Syntax


./compile_all.sh [source_directory] [options]

Examples

#### 1. Compile Current Directory (Recursive)


cd jack-compiler
./compile_all.sh .

This recursively finds all .jack files in the current directory and subdirectories, and compiles them.

#### 2. Compile Specific Directory


./compile_all.sh src/

Compiles all .jack files in src/ and all its subdirectories.

#### 3. Preview Without Compiling (Dry Run)


./compile_all.sh . --dry-run

Shows all files that would be compiled without actually compiling them. Useful for verifying the script will process the correct files.

#### 4. Clean Old VM Files First


./compile_all.sh . --clean

Removes all existing .vm files in the directory tree before compiling. Useful when rebuilding a project from scratch.

#### 5. Verbose Output


./compile_all.sh . --verbose

Shows detailed output for each compilation step, including file names and status.

#### 6. Combined Options


./compile_all.sh src/ --clean --verbose

Removes old .vm files, then compiles all Jack files in src/ with detailed output.

Options Reference

| Option | Short | Description |

|--------|-------|-------------|

| --help | -h | Show help message and exit |

| --dry-run | | Preview files without compiling |

| --clean | | Remove all .vm files before compiling |

| --verbose | -v | Show detailed output for each file |

| --output | -o | Specify output directory (not recommended) |

Common Workflows

Workflow 1: Initial Project Setup


# 1. Navigate to project directory
cd my_project

# 2. Preview what will be compiled
/path/to/jack-compiler/compile_all.sh . --dry-run

# 3. Compile all files
/path/to/jack-compiler/compile_all.sh .

# 4. Check for errors
# (review output above)

Workflow 2: Rebuild After Changes


# 1. Clean old VM files
./compile_all.sh . --clean

# 2. Recompile everything
./compile_all.sh .

Workflow 3: Troubleshooting Compilation Errors


# 1. Run with verbose output to see which file fails
./compile_all.sh . --verbose

# 2. Fix the problematic Jack file

# 3. Recompile
./compile_all.sh .

Workflow 4: Integration with Build System


#!/bin/bash
# build.sh - Simple build script

echo "Building Jack project..."

# Clean
./compile_all.sh src/ --clean

# Check for errors
if [ $? -ne 0 ]; then
    echo "Build failed!"
    exit 1
fi

echo "Build successful!"

# Run tests (if you have any)
# pytest -v

Tips & Tricks

1. Check Compilation Without Running It

Use dry-run to verify the script will process the correct files:


./compile_all.sh . --dry-run

2. Count Your Jack Files


find . -name "*.jack" | wc -l

3. List All Jack Files


find . -name "*.jack" | sort

4. Remove All VM Files


find . -name "*.vm" -delete

5. Compare Jack and VM File Counts


# Should match if compilation succeeded
find . -name "*.jack" | wc -l
find . -name "*.vm" | wc -l

6. Get Detailed Compilation Report


./compile_all.sh . --verbose > compilation_report.txt 2>&1

Troubleshooting

Issue: "Script not found" or "Permission denied"

Solution: Make sure the script is executable:


chmod +x compile_all.sh

Issue: "Python 3 is not installed"

Solution: Install Python 3:


# macOS
brew install python3

# Ubuntu/Debian
sudo apt-get install python3

# Windows (from python.org or Microsoft Store)

Issue: "Compiler script not found"

Solution: Run the script from the jack-compiler directory:


cd jack-compiler
./compile_all.sh .

Issue: Some files failed to compile

Solution: Run with verbose mode to see details:


./compile_all.sh . --verbose

Then check the Jack syntax in the failing files using QUICK_REFERENCE.md.

Issue: Script takes a long time

Solution: This is normal for large projects. Use dry-run to verify without compiling:


./compile_all.sh . --dry-run

Advanced Usage

Compile Specific Subdirectory


./compile_all.sh src/system/

Exclude Certain Directories

If you want to skip some directories, either:

1. Move them outside the source tree

2. Rename .jack files to a different extension temporarily

Use with Version Control

Add compiled .vm files to .gitignore if you prefer:


# .gitignore
*.vm

Then regenerate them with:


./compile_all.sh . --clean

Monitor Compilation in Real-Time

Use verbose mode and pipe to a log file:


./compile_all.sh . --verbose | tee compilation.log

Script Architecture

The script performs these steps:

1. Parse Arguments - Process command-line options

2. Verify Environment - Check compiler and Python availability

3. Find Files - Recursively find all .jack files

4. Display Statistics - Show files found and directories affected

5. Clean (Optional) - Remove old .vm files if --clean is used

6. Compile - Process each Jack file sequentially

7. Report Results - Display summary and any errors

Performance

Compilation time depends on:

  • Number of Jack files
  • Complexity of each file
  • Disk I/O speed
  • System performance

Typical rates:

  • Simple files: ~0.1s each
  • Complex files: ~0.5s each
  • Projects: ~100-1000 files per minute

FAQ

Q: Can I compile to a different directory?

A: Not recommended. The script generates .vm files in the same directories as .jack files to preserve the project structure.

Q: What if I have both .jack and .vm files with the same name?

A: The .vm files will be overwritten by the compilation.

Q: Can I run multiple compilations in parallel?

A: The current script runs sequentially. For parallel compilation, modify the script to use GNU Parallel or xargs.

Q: How do I stop the compilation if it fails?

A: The script continues through all files but reports failures at the end. To stop on first error, modify the script to remove error_files+= line.

Q: Can I use this script on Windows?

A: Yes, using WSL (Windows Subsystem for Linux) or Git Bash.
