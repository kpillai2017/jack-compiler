Welcome to the Jack Compiler

The Jack Compiler is a complete, production-ready compiler that translates Jack source code into Hack Virtual Machine (VM) bytecode. Built with ANTLR4 (Terence Parr's industry-standard parser generator), it implements the full Jack language specification from the nand2tetris course.

✅ Key Highlight: This compiler generates VM code that is 100% compatible with the reference implementation and runs perfectly in the web-ide VM simulator!

What is the Jack Language?

Jack is a high-level object-oriented programming language designed for the nand2tetris course. It's similar to Java or C++, featuring:

  • Object-Oriented: Classes, objects, methods
  • Typed System: int, boolean, String, custom classes
  • Control Flow: if/else, while loops
  • Arrays: Single-dimensional dynamic arrays
  • Memory Management: Garbage collection support

What Does This Compiler Do?

The compiler takes Jack source code (.jack files) and translates them into Hack Virtual Machine code (.vm files). This VM code can then be further compiled to Hack machine code and run on the Hack computer simulator.

Compilation Pipeline: 
Jack Source Code (.jack)
        ↓
    [Lexer] - Tokenization
        ↓
    [Parser] - Syntax analysis (ANTLR4)
        ↓
    [Visitor] - Semantic analysis
        ↓
    [Code Generator] - VM bytecode generation
        ↓
    Hack Virtual Machine Code (.vm)

Quick Start

Ready to get started? Follow these simple steps:

1. Navigate to the jack-compiler directory
2. Run: pip install -e ".[dev]"
3. Compile: jackc program.jack -o program.vm
4. Use the generated program.vm with the nand2tetris tools
