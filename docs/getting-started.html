Installation

Prerequisites

Before you start, make sure you have:

  • Python 3.8 or higher - Download from python.org
  • Java 11 or later - For running the ANTLR4 tool
  • Git - To clone the repository (optional)
Checking Your System: 
python3 --version  # Should show Python 3.8+
java -version      # Should show Java 11+

Quick Setup (Recommended)

1Navigate to the compiler directory

cd jack-compiler

2Run the automated setup script

bash setup.sh

This script automatically:

  • Checks for Java installation
  • Downloads ANTLR4 (if needed)
  • Generates the parser from the grammar
  • Installs Python dependencies
✅ That's it! The compiler is now ready to use.

Your First Compilation

1Create a simple Jack program

cat > hello.jack << 'EOF'
class Main {
    function void main() {
        do Output.printString("Hello, World!");
        do Output.println();
        return;
    }
}
EOF

2Compile it to VM code

python src/compiler.py hello.jack -o hello.vm

3Check the generated VM code

cat hello.vm

You should see the Hack VM code with proper indentation and labels.

Command-Line Usage

Basic Syntax

python src/compiler.py <input.jack> -o <output.vm>

Examples

Task Command
Compile single file python src/compiler.py program.jack -o program.vm
Compile with default output name python src/compiler.py program.jack
Get help python src/compiler.py --help

Batch Compilation

For projects with multiple files, use the batch compilation script to compile entire directories recursively:

Basic Usage

./compile_all.sh src/

Useful Options

Option Description
--dry-run Preview files without compiling
--clean Remove old .vm files before compiling
--verbose Show detailed compilation progress
--help Display help information

Examples

# Compile all Jack files in src/ and subdirectories
./compile_all.sh src/

# Preview without compiling
./compile_all.sh src/ --dry-run

# Clean and rebuild
./compile_all.sh src/ --clean

# Detailed output
./compile_all.sh src/ --verbose

Testing the Installation

Run the test suite

python tests/test_compiler.py

You should see "✓ All tests passed!" if everything is working correctly.

Compile the examples

./compile_all.sh examples/

This compiles all example programs (HelloWorld, Math, Loop, Point, Array).

Troubleshooting

Python not found

Solution: Make sure Python 3.8+ is installed and in your PATH. Try python3 --version instead of python --version.

Java not found

Solution: Install Java from oracle.com or use your package manager (e.g., brew install openjdk on macOS).

Permission denied on setup.sh

Solution: Run chmod +x setup.sh first, then bash setup.sh.

For more help, see the FAQ section.
