Batch Compilation Examples

This document provides practical examples of using the compile_all.sh script for various scenarios.

Quick Reference


# Help
./compile_all.sh --help

# Compile current directory recursively
./compile_all.sh .

# Compile specific directory
./compile_all.sh src/

# Preview without compiling
./compile_all.sh . --dry-run

# Clean old VM files and recompile
./compile_all.sh . --clean

# Detailed output
./compile_all.sh . --verbose

# Combine options
./compile_all.sh src/ --clean --verbose

Example 10: Integration with Build System

Scenario

You want a complete build script that compiles, runs tests, and reports results.

build.sh Script


#!/bin/bash

echo "========================================"
echo "Building Jack Project"
echo "========================================"
echo ""

# Navigate to project
cd $(dirname "$0")

# Clean old files
echo "Step 1: Cleaning old VM files..."
./compile_all.sh src/ --clean
BUILD_RESULT=$?

if [ $BUILD_RESULT -ne 0 ]; then
    echo "Build failed at compilation step!"
    exit 1
fi

echo ""
echo "Step 2: Running tests..."
python3 tests/test_compiler.py
TEST_RESULT=$?

if [ $TEST_RESULT -ne 0 ]; then
    echo "Build failed at testing step!"
    exit 1
fi

echo ""
echo "========================================"
echo "Build successful!"
echo "========================================"

Usage


bash build.sh

Tips for Effective Batch Compilation

Tip 1: Always Preview First

Use --dry-run to verify the script will process the right files:


./compile_all.sh . --dry-run

Tip 2: Use Verbose for Large Projects

For projects with many files, use verbose mode:


./compile_all.sh . --verbose | tee build.log

Tip 3: Clean Before Rebuild

Always clean when rebuilding to avoid stale files:


./compile_all.sh . --clean

Tip 4: Check File Counts

Verify the number of .jack and .vm files match:


find . -name "*.jack" | wc -l  # Should match...
find . -name "*.vm" | wc -l    # ...this count

Tip 5: Save Build Logs

Keep logs of builds for troubleshooting:


./compile_all.sh . > build-$(date +%Y%m%d-%H%M%S).log 2>&1

Troubleshooting Examples

Issue: Script Not Found


# Make it executable
chmod +x compile_all.sh

# Then run
./compile_all.sh .

Issue: Python Not Found


# Install Python
brew install python3        # macOS
sudo apt-get install python3 # Linux

# Verify
python3 --version

Issue: Compiler Not Found


# Make sure you're in jack-compiler directory
cd jack-compiler
./compile_all.sh examples/

Issue: Some Files Failed


# Run with verbose to see errors
./compile_all.sh . --verbose

# Fix the problematic file
# Then recompile
./compile_all.sh .
