Batch Compilation Examples

Worked examples for jackc's batch options. The output shown is real; colour codes are omitted. For the full option reference see the Batch Compilation Guide.

Quick Reference

jackc src/                          # one directory
jackc -r src/                       # directory tree, output next to sources
jackc -r src/ -o build/             # directory tree, output mirrored under build/
jackc -r --clean --dry-run src/     # preview a clean rebuild
jackc -r --clean src/               # clean rebuild
jackc src/Main.jack                 # single file

The examples below use this project:

src/
├── Main.jack
└── game/
    ├── Ghost.vm          ← leftover from a deleted class
    ├── Math.jack
    └── objects/
        └── Point.jack

Example 6: A File With Errors

After adding a broken src/game/Broken.jack:

$ jackc -r --clean src/
...
[2/4] ✗ COMPILATION FAILED: src/game/Broken.jack
  2 syntax error(s):
  src/game/Broken.jack:3:17: mismatched input ';' expecting {'true', 'false', 'null', 'this', '-', '~', '(', INTEGER, STRING_LITERAL, IDENTIFIER}
  src/game/Broken.jack:5:5: mismatched input '}' expecting {'true', 'false', 'null', 'this', '-', '~', ';', '(', INTEGER, STRING_LITERAL, IDENTIFIER}

[3/4] ✓ SUCCESS: src/game/Math.jack
  → src/game/Math.vm
...
────────────────────────────────────────────────────────────
Compiled: 3  Failed: 1  Total: 4
✗ SOME COMPILATIONS FAILED
  ✗ src/game/Broken.jack
════════════════════════════════════════════════════════════
$ echo $?
1

The other files are still compiled. Because --clean was used, no stale Broken.vm is left behind.

Example 7: Only Part of a Tree

Point jackc at the sub-directory you want:

jackc -r src/game/

Example 8: Single File

jackc src/Main.jack                  # → src/Main.vm
jackc src/Main.jack -o out/Main.vm   # → out/Main.vm (directories created)
jackc --clean src/Main.jack          # removes only src/Main.vm first
jackc -n src/Main.jack               # shows the plan; writes nothing

Example 9: Saving Output to a Log

jackc -r src/ > build.log 2>&1

Colour is disabled automatically when output is redirected (or when NO_COLOR is set).

Example 10: Build Systems

Make

build:
    jackc -r --clean src/ -o build/

Shell

if jackc -r src/; then
    echo "Build OK"
else
    echo "Build failed" >&2
    exit 1
fi
