General Questions

What is the Jack Compiler?

The Jack Compiler is a complete implementation of a compiler for the Jack language (from the nand2tetris course). It translates Jack source code (.jack files) into Hack Virtual Machine bytecode (.vm files). The compiler is built using ANTLR4, a powerful parser generator.

What is ANTLR4?

ANTLR4 (Another Tool for Language Recognition) is a parser generator created by Terence Parr. Instead of writing a parser by hand, you define a grammar (formal description of language syntax), and ANTLR4 automatically generates the lexer and parser. This is used by industry tools and makes compiler development much easier.

What is the nand2tetris course?

nand2tetris (https://www.nand2tetris.org/) is an educational course that teaches computer architecture and software development from the ground up. Students start with NAND gates and build a complete computer, including an operating system and compiler. The Jack language is used in the course for application development.

Installation & Setup

What are the system requirements?
  • Python 3.8+ - The compiler is written in Python
  • Java 11+ - For running the ANTLR4 tool
  • ~50 MB disk space - For dependencies
  • Any modern operating system (Linux, macOS, Windows)
How do I check if I have Java installed?

Run this command in your terminal:

java -version

If Java is installed, you'll see version information. If not, install it from oracle.com or use your package manager.

What if installation fails?

Common issues and solutions:

  • Editable install fails: Upgrade pip first with pip install --upgrade pip
  • Java not found: Install Java from oracle.com
  • Python not found: Use python3 instead of python
  • Network error: Check your internet connection and try again

Compilation & Usage

How do I compile a Jack file?

Use the compiler command:

jackc program.jack -o program.vm

Replace program.jack with your filename and program.vm with the desired output file.

Can I compile multiple files at once?

Yes! Pass a directory instead of a file:

jackc src/ -o bin/

This compiles every .jack file in that directory (one .vm per class). Without -o, output is written alongside the sources.

What is the --verbose option?

The -v / --verbose option prints a full Python traceback if the compiler hits an internal error:

jackc src/ -v

Helpful when reporting a bug.

Is there a graphical version?

Yes: jackc-gui compiles in a window and shows each Jack class next to the VM code it turns into, with errors marked under the line. Install it with the gui extra, which adds pygame:

pip install -e ".[gui]"
jackc-gui src/

See The Compiler Window.

Can I edit my code in jackc-gui?

No, it's a viewer. Edit in your usual editor, save, and press Ctrl+R in the window to recompile. Ctrl+E jumps to the next error.

How do I hide warnings, or make them fail the build?

jackc -w src/ hides warnings. jackc --werror src/ treats them as errors, so a file with warnings gets no .vm file and the exit status is 1.

In jackc-gui, start with --werror or press Ctrl+W to switch it on and off while you work. The STATUS box says which is in use.

Common Errors & Solutions

Error: "expected ';' after ..." (or another syntax error)
Problem: Your Jack code has a syntax error

The message shows the file, line and column, and marks the exact spot:

Main.jack:3:18: error: expected ';' after 'x'
 3 |         var int x
   |                  ^
   = help: every statement and declaration ends with ';'

Solution:

  • Check for missing semicolons at the end of statements
  • Verify all braces are properly matched (unexpected end of file usually means a missing })
  • Fix the first error first: later ones are often caused by it
  • Compare with the example programs in examples/
Error: "'y' is not declared"
Problem: You're using a variable that hasn't been declared

If it looks like a typo, the compiler suggests the name you probably meant: = help: did you mean 'count'?

Solution:

  • Make sure the variable is declared with var, field or static
  • Check for typos in variable names (Jack is case-sensitive)
  • Ensure the variable is declared before use

Example:

var int x;  // ✓ Correct
let x = 5;

let y = 10; // ✗ Error: 'y' is not declared

Every message the compiler can print is listed in the Error Detection guide.

Error: "File not found"
Problem: The compiler can't find your input file

Solution:

  • Verify the filename is spelled correctly
  • Check the file exists in the current directory
  • Use full paths if the file is in a subdirectory: jackc src/program.jack
Why is the compiled code so much longer than my source?

VM code is more verbose than Jack source code. For example, string literals are expanded to many instructions (one per character). This is normal!

Jack string: "Hi" (4 characters)

VM code: ~20 instructions

Language & Compiler Features

What Jack language features are supported?

The compiler supports the full Jack language specification:

  • Classes with fields and methods
  • All data types: int, boolean, String, custom classes
  • All statement types: let, if/else, while, do, return
  • Expressions with proper operator precedence
  • Arrays (single-dimensional)
  • String literals and built-in functions
  • Comments (single-line and block)
Can I use the Jack standard library?

Yes! The compiler supports calls to standard library functions like:

  • Output.printInt(), Output.printString()
  • String.new(), String.appendChar()
  • Array.new()
  • Memory.alloc(), Memory.deAlloc()
  • Math.multiply(), Math.divide(), etc.
  • And many more!
Is recursion supported?

Yes! The compiler fully supports recursive function calls. Each function call maintains its own stack frame, so recursion works naturally.

What about object-oriented features?

The compiler supports:

  • Class definition with fields and methods
  • Constructors with memory allocation
  • Instance methods with implicit this pointer
  • Static methods (functions)
  • Method calls on objects

Output & Compatibility

Is the output compatible with nand2tetris tools?
Yes! The generated VM code is 100% compatible with the nand2tetris VM simulator and other tools.
Can I use the generated VM code with the web-ide?
Yes! The output is fully compatible with the nand2tetris web-ide VM simulator. You can run the generated .vm files directly.
What should I do with the .vm output?

The generated .vm files can be:

  • Loaded into the nand2tetris web-ide simulator
  • Further compiled to Hack assembly using the VM Translator
  • Used with any nand2tetris-compatible tools
  • Combined with other VM files for larger projects

How does the compiler handle operator precedence?

The ANTLR4 grammar is designed so that the parse tree naturally respects operator precedence. Multiplication and division are parsed before addition and subtraction.

Example: 1 + 2 * 3 generates code that multiplies 2*3 first, then adds 1.

How are strings implemented?

Jack strings are implemented as String objects (from the standard library). The compiler generates code that:

  1. Calls String.new(length) to create a new string
  2. For each character, calls String.appendChar(code)
  3. Results in a String object on the stack
