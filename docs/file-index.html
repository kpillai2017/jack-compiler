File Organization

Core Compiler (`jack_compiler/`)


jack_compiler/
├── __main__.py (enables `python -m jack_compiler`)
├── compiler.py (~580 lines)
│   Main entry point and CLI driver
│   - Command-line argument parsing (-r, --clean, -n, -w, --werror, ...)
│   - File I/O handling and batch compilation
│   - Prints errors and warnings with the source line and a ^~~~ marker
│   Usage: jackc input.jack -o output.vm
│
├── diagnostics.py (~290 lines)
│   Diagnostic records (line, column, severity, message, help, notes)
│   - Collects ANTLR4 lexer/parser errors and rewrites them in plain English
│   - render(): the compiler-style text jackc prints (jackc-gui draws the
│     same layout with gui/annotate.py)
│
├── checker.py (~390 lines)
│   Semantic checks, run before any VM code is generated
│   - Errors: undeclared / duplicate names, wrong argument counts,
│     methods called from functions, missing return, ...
│   - Warnings: unused variables, unreachable code, ...
│   - "did you mean ...?" suggestions
│
├── compiler_visitor.py (~690 lines)
│   ANTLR4 visitor pattern implementation
│   - Parse tree traversal
│   - Symbol table management during compilation
│   - Code generation orchestration
│   Key methods: visit_* for each language construct
│
├── symbols.py (~160 lines)
│   Symbol table implementation
│   - Class-level scope (static, field)
│   - Subroutine-level scope (local, arguments)
│   Classes: SymbolTable, SymbolInfo, VarKind enum
│
├── codegen.py (~240 lines)
│   Hack VM code generator
│   - Instruction emission, memory segments, arithmetic and logic
│   - Control flow (labels, jumps) and function management
│
├── integrations.py
│   Finds jackvm-py (env var -> config file -> same Python environment -> PATH);
│   an identical copy lives in jackvm-py (tests/test_shared_files.py checks)
│
├── locate_app.py
│   "Where is JackVM?": the folder chooser Ctrl+J opens when it isn't found;
│   saves the answer in the config file (also shared with jackvm-py)
│
├── __init__.py
│   Package initialization and exports
│
├── gui/  (jackc-gui: the compiler window, needs pygame; see gui.html)
│   ├── main.py         command-line options; starts the picker or window
│   ├── session.py      compiles every file on a background thread (no pygame)
│   ├── window.py       the main window: layout, keys, drawing
│   ├── annotate.py     diagnostics -> shaded lines and ^~~~ rows
│   ├── syntax.py       Jack and VM syntax colouring (no pygame)
│   ├── panel.py        STATUS / FILES / PROBLEMS / OUTPUT / SHORTCUTS boxes
│   ├── file_picker.py  choose a .jack file or folder
│   ├── run_in_vm.py    Ctrl+J: compile to a temp folder and start JackVM
│   └── theme.py        colours and fonts (matches jackvm-py)
│
└── antlr_generated/
    └── grammar/
        ├── JackLexer.py (auto-generated)
        ├── JackParser.py (auto-generated)
        ├── JackListener.py (auto-generated)
        ├── JackVisitor.py (auto-generated)
        └── __init__.py

Grammar Definition (`grammar/`)


grammar/
└── Jack.g4 (200 lines)
    Complete ANTLR4 grammar for Jack language
    - 30+ tokens (keywords, operators, symbols)
    - 25+ grammar rules
    - Full expression and statement support
    - Comment and string literal handling
    Run: java -jar antlr-4.13.0-complete.jar -Dlanguage=Python3 -visitor -o jack_compiler/antlr_generated grammar/Jack.g4

Troubleshooting

"ANTLR-generated files not found"

→ Run: pip install -e ".[dev]"

"Java not found"

→ Install Java: brew install openjdk (macOS) or system package manager

"Syntax error in my Jack program"

→ Check your code against QUICK_REFERENCE.md

→ The compiler will show the error location

"Undefined variable error"

→ Make sure all variables are declared with var, field, or static

Integration Points

With nand2tetris Toolchain


1. Jack Source (.jack)
   ↓ [This Compiler]
2. Hack VM Code (.vm)
   ↓ [VMTranslator from nand2tetris]
3. Hack Assembly (.asm)
   ↓ [Hack Emulator or Assembler]
4. Machine Code (.hack)
