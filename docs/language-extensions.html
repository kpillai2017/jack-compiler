Extended Jack: one program, four lessons

A hands-on lab connecting source syntax, execution order, and VM instructions.

HomeGetting startedStandard examplesCompiler architecture

Start with standard Jack's let, if, while, do, and return. Then explore the extensions using the runnable Main.jack source and the full walkthrough with exercises. In a local checkout these are teaching/extensions/Main.jack and teaching/extensions/README.md.

Extensions are opt-in, not standard nand2tetris Jack. They add no VM instructions. The compiler GUI currently uses standard mode. The lesson is outside examples/ so standard-mode batch examples remain valid.

1. Compile and run

From the compiler repository root:

jackc --extensions teaching/extensions/Main.jack -o build/extensions/Main.vm
# With the optional companion jackvm-py installed:
jackvm build/extensions/Main.vm
jackvm --headless --ticks 300000 build/extensions/Main.vm

Run the generated VM rather than the source: automatic source compilation may select standard mode. In Python use JackCompiler(extensions=True). Headless mode renders the pixel screen as ASCII, not a plain-text transcription; the graphical VM is easiest for reading the lesson output.

3. Group 1: literals and comparisons

const int MASK = 0x0F;
const char BADGE = 'A';
let flags |= 0b0010;
if (i >= STOP_AT) { break; }
if (state != State.READY) { /* ... */ }

Hexadecimal 0x0F means 15, binary 0b0010 means 2, and 'A' means character code 65. Literal magnitudes remain 0–32767. Comparisons <=, >=, and != return true (-1) or false (0).

Strings decode \" and \\, plus \n, \r, \t, \b, \f, \0, and \'. Unknown escapes are errors. The lab uses Output.println(): an escaped newline character is not a guarantee of OS display behaviour.

Two traps: operators still evaluate left to right: 1 + 2 * 3 yields 9, not 7. Use parentheses. Standard-mode strings keep backslashes literally; changing mode can change an existing string's meaning.

4. Group 2: initialisers and compound assignment

var Array scores = Array.new(CAPACITY);
var int i = 0, countdown = 3;
let scores[Main.countIndex(i)] += (i * 2) + BONUS;
let total += scores[i];

Initialisers run once in source order, after method/constructor setup and before statements. Locals stay at subroutine start and retain subroutine scope. Reading a later local from an earlier initialiser sees its zeroed local slot, not its eventual initialiser.

CompoundSimple-variable expansion
x += yx = x + y
x -= yx = x - y
x *= yx = x * y
x /= yx = x / y
x &= yx = x & y
x |= yx = x | y

All are used in the full program. For array targets, do not duplicate the index expression in a textual expansion: the compiler evaluates the target once and saves its address and old value on the VM stack across RHS calls. The lab's indexCalls = 5 makes this observable. Bitwise &/| are not short-circuit operators; 2 | 1 is 3 and 3 & 15 remains 3.

5. Group 3: loops and control flow

for (let i = 0; i <= (CAPACITY - 1); let i += 1) {
    if (i = SKIP_AT) { continue; }
    if (i >= STOP_AT) { break; }
    let scores[Main.countIndex(i)] += (i * 2) + BONUS;
    let total += scores[i];
    let processed += 1;
    let flags |= 0b0010;
}

Order: initialise once → condition → body → update → condition. Header let keywords are optional; each assignment is a single assignment, not a declaration or comma list. Any clause may be absent; for (;;) repeats without a condition.

  • continue runs a for-loop update, but jumps directly to a while-loop condition.
  • break exits the innermost loop and skips a for-loop update.
  • return exits the whole subroutine.
  • Controls outside loops are errors. Unreachable statements are warned about in extension mode.

The countdown loop decrements before checking whether to continue. Otherwise a skip might prevent progress. Conditions follow Jack's Boolean convention, not arbitrary-integer truthiness. An endless loop with a reachable break still needs a return on paths after it.

6. Group 4: constants and enums

const int CAPACITY = 8, STOP_AT = 6, SKIP_AT = 2;
const boolean RUNNING = true;
enum State { READY, ACTIVE = 5, DONE }

Constants have int, char, or boolean type, cannot be assigned or indexed, and allocate no VM storage. Subroutine constants are also supported. Local names may shadow class constants; Main.CAPACITY explicitly selects a class constant.

Enums are scoped integer names, not distinct types: READY is 0, ACTIVE is 5, DONE is 6. Explicit values reset subsequent numbering. Use State.DONE, not bare DONE.

Constant expressions allow grouping, unary minus/not, existing binary operators, primitive literals and other constants/members. Forward references work; cycles, runtime variables/calls, strings, null/this, and division by zero are rejected. Evaluation is left-to-right signed 16-bit wrapping, with division truncated toward zero. Boolean constants must be 0/-1 and chars 0–32767; implicit enum overflow is an error.

Declarations/references are limited to the current source class: no cross-file exports or enum type declarations. Enum names cannot collide with variables/constants. const, enum, for, break, and continue are reserved only in extension mode.

7. Inspect the generated VM

  • Constants/members become literal pushes; negative values additionally use neg or not.
  • <= → gt; not, >= → lt; not, != → eq; not.
  • For loops have condition, update and exit labels. Compare continue/break targets.
  • Array updates preserve the target on the stack. Initialisers follow the function prologue.

Allocation/disposal still use the ordinary OS: Array.new and scores.dispose().

8. Exercises and checkpoints

  1. Set SKIP_AT to 3: total 29, processed 5, calls 5. Explain the removed score.
  2. Set STOP_AT to 4, retaining SKIP_AT = 2: total 11, processed 3, calls 3.
  3. Remove the skip: total 36, processed 6, calls 6.
  4. Change ACTIVE to 10: DONE and the final state become 11.
  5. Try assigning CAPACITY, using a runtime call in a constant expression, or break outside a loop. Explain the errors.
  6. Rewrite the scoring loop as standard while plus flags. Where must its update run?

9. Verify the lesson

python3 -m pytest tests/test_teaching_extensions.py -q
# Optional sibling VM runtime:
PYTHONPATH="../jackvm-py" python3 -m pytest tests/test_teaching_extensions.py -q

Tests cover compilation, standard-mode rejection, documentation/source consistency, results, and exercise variations. Runtime checks read Main's five static results after the VM halts; the stack top is not a reliable return value because Sys.init discards Main.main's result.
