Example 1: Hello World

📌 Simple String Output

The simplest Jack program: print a message and exit.

Input (HelloWorld.jack)
class Main {
    function void main() {
        do Output.printString(
            "Hello, World!");
        do Output.println();
        return;
    }
}
Output (HelloWorld.vm)
function Main.main 0
    push constant 13
    call String.new 1
    push constant 72
    call String.appendChar 2
    push constant 101
    call String.appendChar 2
    push constant 108
    call String.appendChar 2
    push constant 108
    call String.appendChar 2
    push constant 111
    call String.appendChar 2
    push constant 44
    call String.appendChar 2
    push constant 32
    call String.appendChar 2
    push constant 87
    call String.appendChar 2
    push constant 111
    call String.appendChar 2
    push constant 114
    call String.appendChar 2
    push constant 108
    call String.appendChar 2
    push constant 100

    push constant 33

    pop temp 0

    pop temp 0
    push constant 0

Key Points:
  • String literals are built character by character
  • Each character is represented by its ASCII code
  • Function calls use call instruction with argument count
  • Return values are discarded with pop temp 0

Example 2: Variables and Arithmetic

📌 Variable Declaration and Math

Demonstrates variable assignment and arithmetic operations.

Input (Math.jack)
class Math {
    function void main() {
        var int x, y, sum;
        
        let x = 10;
        let y = 20;
        let sum = x + y;
        
        do Output.printInt(sum);
        return;
    }
}
Output (Math.vm)
function Math.main 3
    push constant 10
    pop local 0
    push constant 20
    pop local 1
    push local 0
    push local 1
    add
    pop local 2
    push local 2
    call Output.printInt 1
    pop temp 0
    push constant 0
    return
Key Points:
  • Function declares 3 local variables (function Math.main 3)
  • Variable assignment: push value, then pop to variable location
  • Arithmetic: push both operands, then emit operator
  • Local variables are stored in the "local" memory segment

Example 3: Loops

📌 While Loop with Accumulation

Shows how loops are compiled to labels and conditional jumps.

Input (Loop.jack)
class Loop {
    function void main() {
        var int i, sum;
        
        let i = 0;
        let sum = 0;
        
        while (i < 10) {
            let i = i + 1;
            let sum = sum + i;
        }
        
        do Output.printInt(sum);
        return;
    }
}
Output (Loop.vm)
function Loop.main 2
    push constant 0
    pop local 0
    push constant 0
    pop local 1
    label Loop_0
    push local 0
    push constant 10
    lt
    not
    if-goto Loop_1
    push local 0
    push constant 1
    add
    pop local 0
    push local 1
    push local 0
    add
    pop local 1
    goto Loop_0
    label Loop_1
    push local 1
    call Output.printInt 1
    pop temp 0
    push constant 0
    return
Key Points:
  • label Loop_0: Loop start marker
  • Condition is negated, then if-goto jumps if false
  • goto Loop_0: Jump back to start
  • label Loop_1: After loop

Example 4: Object-Oriented Programming

📌 Class with Fields and Methods

Demonstrates classes, constructors, methods, and object references.

Input (Point.jack)
class Point {
    field int x, y;
    
    constructor Point new(
        int px, int py) {
        let x = px;
        let y = py;
        return this;
    }
    
    method void setX(int val) {
        let x = val;
        return;
    }
    
    method int getX() {
        return x;
    }
}
Output (Point.vm)
function Point.new 0
    push constant 2
    call Memory.alloc 1
    pop pointer 0
    push argument 0
    pop this 0
    push argument 1
    pop this 1
    push pointer 0
    return

function Point.setX 0
    push argument 0
    pop pointer 0
    push argument 1
    pop this 0
    push constant 0
    return

function Point.getX 0
    push argument 0
    pop pointer 0
    push this 0
    return
Key Points:
  • Constructor allocates memory: push constant 2 (2 fields)
  • Field variables use this segment
  • Methods receive implicit this as first argument
  • pop pointer 0 sets the this pointer

Example 5: Arrays

📌 Array Operations

Shows array allocation, indexing, and iteration.

Input (Array.jack)
class Array {
    function void main() {
        var Array arr;
        var int i;
        
        let arr = Array.new(3);
        let arr[0] = 10;
        let arr[1] = 20;
        let arr[2] = 30;
        
        let i = 0;
        while (i < 3) {
            do Output.printInt(
                arr[i]);
            let i = i + 1;
        }
        return;
    }
}
Output (Array.vm)
function Array.main 2
    push constant 3
    call Array.new 1
    pop local 0
    push constant 0
    push local 0
    add
    push constant 10
    pop temp 0
    pop pointer 1
    push temp 0
    pop that 0
    push constant 1
    push local 0
    add
    push constant 20
    pop temp 0
    pop pointer 1
    push temp 0
    pop that 0
    push constant 2
    push local 0
    add
    push constant 30
    pop temp 0
    pop pointer 1
    push temp 0
    pop that 0
    label Array_0
    push local 1
    push constant 3
    lt
    not
    if-goto Array_1
    push local 1
    push local 0
    add
    pop pointer 1
    push that 0
    call Output.printInt 1
    pop temp 0
    push local 1
    push constant 1
    add
    pop local 1
    goto Array_0
    label Array_1
    push constant 0
    return
Key Points:
  • Array assignment: push index, push base, add, then store
  • Array access: push base, push index, add, then pop pointer 1
  • that segment is used for dereferencing array elements
